# Монетизация !один

**Дата:** 2026-05-16  
**Статус:** Черновик — до релиза не актуально, но стратегия должна быть выбрана заранее

---

## Принципы

Приложение для людей в уязвимом состоянии. Монетизация не должна:
- Создавать классы пользователей (премиум видит других людей, бесплатный — нет)
- Ограничивать доступ к функциям, связанным с поддержкой (@один, комнаты, дыхание)
- Выглядеть как «платите и вам станет лучше»

Допустимо монетизировать: персонализацию, эстетику, инструменты самопознания — то, что улучшает опыт, но не блокирует базовый доступ.

## Модели (от приоритетной к опциональной)

### 1. Подписка «!один+» — основная модель

**Цена:** ~199 ₽/мес или ~1490 ₽/год  
**Что включено:**

| Функция | Бесплатно | !один+ |
|---------|-----------|--------|
| Тест раз в сутки | ✅ | ✅ |
| Лента, комнаты, глобальный чат | ✅ | ✅ |
| @один (ИИ-чат) | 5 сообщений/день | Без лимита |
| Дыхание, рыбалка | ✅ | ✅ |
| История уровней | 7 дней | Вся история |
| Психометрические тесты | 1 тест/неделю | Все тесты, без ожидания |
| Личная аналитика | Текущая неделя | Архив + тренды |
| Кастомный статус профиля | ✅ | ✅ |
| Скрытый режим (невидимка в комнатах) | ❌ | ✅ |
| Экспорт своих данных (PDF) | ❌ | ✅ |

**Почему это работает:** @один — самая эмоционально значимая фича. 5 сообщений в день достаточно для знакомства, но недостаточно в тяжёлый день. Апгрейд ощущается как «больше поддержки», не как «доступ к людям».

---

### 2. Разовые покупки (in-app)

**«Поддержать проект»** — донат без каких-либо бонусов (99 / 299 / 999 ₽).  
Для тех, кому приложение помогло и кто хочет поддержать других пользователей.  
Формулировка: «Твои деньги идут на поддержание серверов и модерацию — чтобы приложение оставалось бесплатным для тех, кому сейчас совсем плохо».

---

### 3. B2B / Институциональный (долгосрочно, после масштаба)

**Партнёрство с HR-отделами:** корпоративные подписки для сотрудников с мониторингом burnout (анонимная агрегированная аналитика по команде, без доступа к личным данным).  
**Университеты:** лицензии для студентов.  
**НКО/фонды:** грантовое финансирование как инструмент ментального здоровья.

Минимальный масштаб для B2B: 10 000+ MAU.

---

### 4. Что точно не делаем

- ❌ Реклама — несовместима с доверием и темой приложения
- ❌ Продажа данных — психометрика и уровни состояния, категорически нет
- ❌ Freemium с блокировкой базового общения — люди в кризисе не должны упираться в пейволл
- ❌ «Голоса» или виртуальная валюта — не наша аудитория

## Техническая реализация (когда придёт время)

**RevenueCat** — стандарт для Expo/RN:
- Кросс-платформенные подписки (App Store + Google Play)
- Webhook → Supabase Edge Function → поле `subscription_tier` в таблице `users`
- RLS-политики проверяют `subscription_tier` для ограниченных функций

```sql
-- Добавить в users:
ALTER TABLE users ADD COLUMN subscription_tier TEXT DEFAULT 'free' 
  CHECK (subscription_tier IN ('free', 'plus'));
ALTER TABLE users ADD COLUMN subscription_expires_at TIMESTAMPTZ;
```

**Лимит @один для бесплатных:**  
Edge Function `ai-chat` проверяет количество сообщений за сутки из `ai_chat_messages` — если `>= 5` и `tier = 'free'`, возвращает `{ limit: true }`.

## Метрики для решения о запуске монетизации

Запускать подписку имеет смысл при:
- **DAU ≥ 500** (достаточная база для конверсии)
- **Retention D30 ≥ 20%** (пользователи остаются — есть за что платить)
- **@один usage ≥ 3 сообщ/день у 30%+ пользователей** (фича ценна)

До этих цифр — бесплатно для всех, фокус на росте и доверии.
