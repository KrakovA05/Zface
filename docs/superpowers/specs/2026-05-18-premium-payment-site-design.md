# Premium Payment Site Design

**Goal:** Статичная страница оплаты Premium-подписки через ЮКасса. Пользователь платит → сайт вызывает Supabase → `users.is_premium = true` → приложение разблокирует функции.

**Не нужно:** сложный сайт, регистрация, личный кабинет, маркетинг. Только страница оплаты.

---

## Флоу

```
Пользователь в приложении
  → тапает «Оформить Premium»
  → открывается браузер с сайтом
  → URL содержит userId: https://[домен]/premium?uid=SUPABASE_USER_ID
  → вводит email (для чека) и нажимает «Оплатить»
  → ЮКасса принимает оплату
  → ЮКасса шлёт webhook на наш сервер
  → сервер ставит is_premium=true в Supabase
  → пользователь возвращается в приложение
  → приложение при следующем запуске видит is_premium=true
```

## Страница (один HTML-файл)

**Что показывает:**
- Название приложения + «Premium»
- Список 5 фич (иконки + текст)
- Цена: 199 ₽/мес или 1490 ₽/год (переключатель)
- Поле email (для чека от ЮКасса — обязательно по 54-ФЗ)
- Кнопка «Оплатить» → инициирует платёж через ЮКасса JS SDK
- После успешной оплаты: текст «Готово! Открой приложение»

**userId передаётся через URL:**
```
https://[домен]/premium?uid=abc123
```
Страница читает `uid` из URL и передаёт в metadata платежа → webhook знает кому ставить `is_premium`.

## ЮКасса

**Что нужно:**
1. Зарегистрироваться на yookassa.ru как физлицо (самозанятый) или ИП
2. Подключить магазин → получить `shopId` и `secretKey`
3. Настроить webhook URL: `https://[supabase-project].supabase.co/functions/v1/yookassa-webhook`
4. Подключить 54-ФЗ (онлайн-касса) — ЮКасса предлагает встроенное решение

**Способы оплаты которые включить:**
- Банковские карты (Visa, Mastercard, Мир)
- СБП (по QR-коду)
- ЮMoney

**Тестовый режим:** ЮКасса даёт тестовый shopId — можно всё проверить без реальных денег.

## Supabase Edge Function: yookassa-webhook

Создать: `supabase/functions/yookassa-webhook/index.ts`

**Что делает:**
1. Принимает POST от ЮКасса
2. Проверяет что `event.type === 'payment.succeeded'`
3. Читает `payment.metadata.user_id`
4. Читает `payment.metadata.period` ('month' или 'year')
5. Считает `premium_expires_at` = сейчас + 30 дней (или 365)
6. Обновляет `users` в Supabase:
   - `is_premium = true`
   - `premium_expires_at = [дата]`
   - `premium_since = [сегодня]` (только если было null)

**Проверка подлинности webhook:**
ЮКасса шлёт IP только со своих серверов — проверять IP или использовать секретный токен в URL.

---

## Supabase Edge Function: check-premium

Опциональная функция для проверки истёкших подписок.

Запускается pg_cron каждый день в 03:00:
```sql
UPDATE users
SET is_premium = false
WHERE is_premium = true
  AND premium_expires_at < NOW();
```

Либо проверять при каждом старте приложения:
```js
// App.js — при загрузке профиля
if (userData.is_premium && userData.premium_expires_at) {
  const expired = new Date(userData.premium_expires_at) < new Date();
  if (expired) {
    store.isPremium = false;
  }
}
```

## Важные нюансы

**54-ФЗ (онлайн-касса):**
ЮКасса предоставляет встроенную кассу — самый простой вариант для начала. Подключается в личном кабинете. Без кассы принимать платежи от физлиц незаконно в РФ.

**Форма регистрации в ЮКасса:**
- Самозанятый: налог 4%, лимит 2.4 млн ₽/год, проще всего
- ИП на УСН: налог 6%, лимита нет, сложнее в оформлении
- Для старта — самозанятый

**Возврат подписки:**
По закону о защите прав потребителей цифровые услуги можно не возвращать — но лучше прописать это в оферте на сайте.

**Оферта:**
На сайте обязательно должна быть ссылка на публичную оферту (условия подписки). Простой текстовый документ, можно сгенерировать через конструкторы договоров.
