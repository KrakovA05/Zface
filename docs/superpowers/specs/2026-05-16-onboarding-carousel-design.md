# Онбординг-карусель — Дизайн

**Дата:** 2026-05-16  
**Статус:** Approved

---

## Контекст

После регистрации и первого теста новый пользователь попадает в приложение без понимания что здесь есть. Карусель — короткое знакомство с ключевыми функциями сразу после теста.

---

## Флоу

```
Test → Recommendations → OnboardingMoment → Карусель → Main
```

- Показывается **только при первом входе** (после первого теста)
- OnboardingMoment остаётся — даёт эмоциональный хук («286 человек с твоим уровнем»), карусель идёт следом как ориентация по функциям
- Карусель можно **открыть повторно из ProfileScreen** («как пользоваться приложением»)

## Визуальный стиль

- **Структура слайда:** скриншот сверху (≈55% высоты), белый блок с текстом снизу
- **Фон скриншота:** `colors.background` (#FAF7F2)
- **Индикатор прогресса:** точки-пилюли внизу текстового блока (активная — широкая, #8B7355; неактивные — узкие, #E8DFD0)
- **Кнопка:** «дальше →» на слайдах 1–4, «начать» на слайде 5; стиль `shared.button` из theme.js
- **Без кнопки «Пропустить»** — карусель короткая, 5 слайдов

---

## Компонент

**Файл:** `ustal/screens/OnboardingCarouselScreen.js`

- Принимает проп `onDone: () => void` — вызывается при нажатии «начать» на последнем слайде
- Использует `FlatList` с `horizontal`, `pagingEnabled`, `scrollEnabled: false` (листание только кнопкой)
- Скриншоты — статичные PNG в `ustal/assets/onboarding/` (захватываются один раз, хранятся как ресурсы)
- Размер изображений: 1170×760 px @3x (390×253 pt), сжатые через `expo-image`

---

## Хранение состояния

- Поле `onboarding_seen BOOLEAN DEFAULT false` в таблице `users`
- Проставляется в `true` при нажатии «начать» (Supabase update)
- При повторном открытии из профиля — состояние игнорируется, карусель показывается всегда
- Fallback: если Supabase недоступен при нажатии «начать» — всё равно переходим в Main, повтор попытки update при следующем запуске

---

## Навигация

```js
// TestScreen после первого теста:
navigation.replace('OnboardingMoment', { level })

// OnboardingMomentScreen → добавить после done:
navigation.replace('OnboardingCarousel')

// OnboardingCarouselScreen → onDone:
await supabase.from('users').update({ onboarding_seen: true }).eq('user_id', store.userId)
navigation.replace('Main')

// ProfileScreen → повторный просмотр:
navigation.navigate('OnboardingCarousel')
// навигация назад → navigation.goBack()
```

## БД

```sql
ALTER TABLE users ADD COLUMN IF NOT EXISTS onboarding_seen BOOLEAN DEFAULT false;
```

RLS: пользователь может обновлять только свою строку (уже покрыто существующей политикой).
