# AI Feed Content — Design Spec
**Дата:** 2026-05-15
**Фаза:** 10 — AI Feed Content
**Приложение:** !один («не один»)

---

## Цель

Лента всегда живая — даже когда реальных пользователей мало. Системный аккаунт @один генерирует ежедневный контент через Gemini API, адаптированный под уровень аудитории. @один иногда отвечает на комментарии — создаёт ощущение диалога и возвращает пользователей через пуши.

---

## Архитектура

### Компоненты

| Компонент | Описание |
|-----------|----------|
| Системный пользователь @один | Запись в `users` с фиксированным UUID, аватар = логотип приложения |
| Edge Function `ai-feed-generator` | Ежедневная генерация 8-11 постов через Gemini 1.5 Flash |
| Edge Function `ai-comment-reply` | Webhook на INSERT в `post_comments` → 35% вероятность ответа с задержкой |
| pg_cron schedule | `0 9 * * *` UTC — ежедневный запуск генератора |
| Database Webhook | INSERT в `post_comments` → `ai-comment-reply` |

### Поток данных

```
pg_cron (09:00 UTC)
  → ai-feed-generator
    → Gemini API (8-11 промптов по уровням)
    → INSERT feed_posts (author_id = @один UUID)

Пользователь пишет комментарий
  → Database Webhook
    → ai-comment-reply
      → 65%: ничего не происходит
      → 35%: Gemini генерирует ответ
        → sleep(rand(600..3600) секунд)  // 10-60 минут
        → INSERT post_comments (author_id = @один UUID)
        → Push-уведомление пользователю
```

## Контент-стратегия

### Распределение по уровням (в день)

| Уровень | Кол-во постов | Тип контента | Стиль |
|---------|--------------|--------------|-------|
| red | 2-3 | 70% валидация, 30% вопрос | Коротко, без призыва к действию |
| yellow | 2-3 | 50% валидация, 50% вопрос | Мягкий вопрос в конце |
| green | 2-3 | 50% вопрос, 30% незаконченная фраза, 20% валидация | Прямой вопрос к диалогу |
| all (все уровни) | 1-2 | Всегда вопрос | Универсальный тон |

### Примеры по уровням

**red** (валидация, без вопроса):
> «Иногда просто лечь и не двигаться — это тоже нормально.»
> «Не всегда нужно что-то делать. Иногда достаточно просто быть.»

**yellow** (мягкий вопрос):
> «Бывают дни когда непонятно что чувствуешь. Сегодня такой?»
> «Что-то среднее между «норм» и «плохо» — у этого нет названия, но оно знакомо.»

**green** (прямой вопрос):
> «Что помогает тебе когда не хочется ни с кем разговаривать?»
> «Сегодня мне тяжело потому что... — закончи предложение.»

**all** (для всех):
> «Что ты делаешь когда не можешь уснуть?»
> «Одна вещь которая точно помогает — для каждого своя. Какая у тебя?»

### Тон (обязательные правила для промптов)

- Никакого токсичного позитива («всё будет хорошо», «держись», «ты справишься»)
- Никаких советов и рекомендаций
- Короткие тексты: 1-3 предложения максимум
- Язык: русский, разговорный, без официоза
- Допустимо молчание и неопределённость как норма

## Визуальное оформление

### Карточка @один в ленте

- **Аватар:** логотип «!один» (иконка приложения)
- **Фон карточки:** `#FAF3E8` вместо `#FFFFFF` — тёплый, едва заметно другой
- **Username:** `@один` с небольшой иконкой ✦ рядом (системный маркер)
- **Всё остальное:** как у обычного поста — лайки, комментарии, timestamp

Изменения в FeedScreen: только стиль карточки (условие `post.author_id === SYSTEM_USER_ID`).

### Ответы @один в комментариях

- Выглядят как обычный комментарий от @один
- Задержка 10-60 минут создаёт ощущение «живого» участия
- Push: «@один ответил на твой комментарий»

## Технические детали

### Системный пользователь

```sql
-- UUID фиксирован, идемпотентный INSERT
INSERT INTO users (user_id, username, level, avatar_url)
VALUES (
  '00000000-0000-0000-0000-000000000001',
  '@один',
  'green',
  '<base64 логотипа или URL>'
) ON CONFLICT DO NOTHING;
```

### Gemini API

- Модель: `gemini-1.5-flash` (бесплатный тир: 1500 запросов/день)
- Ключ: `GEMINI_API_KEY` в Supabase Secrets (`Deno.env.get`)
- Endpoint: `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent`
- Guard: проверка дублей за 20 часов перед INSERT (не генерировать если уже есть посты сегодня)

### ai-comment-reply — логика

1. Webhook получает payload: новый комментарий в `post_comments`
2. Проверить: `post.author_id === SYSTEM_USER_ID` (отвечать только на комментарии к постам @один)
3. Проверить: `comment.author_id !== SYSTEM_USER_ID` (не отвечать на свои же комментарии)
4. `Math.random() > 0.65` → пропустить
5. Сгенерировать ответ через Gemini (короткий, в тему поста и комментария)
6. `await sleep(randomBetween(600_000, 3_600_000))` — 10-60 минут
7. INSERT в `post_comments`

## Защита от рисков

| Риск | Митигация |
|------|-----------|
| GEMINI_API_KEY утечёт в git | Только в Supabase Secrets, никогда в коде |
| Превышение rate limit (1500 RPD) | ~11 постов/день + ~10 ответов = 21 запрос — далеко от лимита |
| Токсичный контент от Gemini | Системный промпт запрещает советы, позитив, триггерные темы; manual review первых 7 дней |
| @один отвечает на каждый комментарий | Вероятность 35%, не более 1 ответа на комментарий |
| Prompt injection от пользователей | Комментарий пользователя передаётся только как контекст, не как инструкция |

---

## Что НЕ входит в эту фазу

- Анализ тональности комментариев (планируется позже)
- Персонализация постов под конкретного пользователя (не только по уровню)
- Модерация AI-контента через интерфейс
- Генерация медиа (только текст)
