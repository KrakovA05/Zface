# Психометрический движок Zface

**Дата:** 2026-05-14  
**Статус:** Согласован, готов к планированию реализации  
**Цель:** Заменить простую цветовую механику (10 вопросов → green/yellow/red) многомерной системой оценки состояния пользователя на основе валидированных психологических тестов, поведенческих метрик и персонализированных рекомендаций.

---

## 1. Общая архитектура

Четыре слоя:

**Сбор данных**
- Валидированные психологические тесты (активно, пользователь проходит)
- Пассивные поведенческие метрики (автоматически из активности в приложении)
- Чекины настроения (уже существуют, входят как сигнал)

**Хранение**
- Новая таблица `user_metrics` — еженедельные снапшоты всех баллов
- Таблица `resources` — база материалов с весами по измерениям
- Таблица `psych_test_results` — результаты каждого прохождения теста

**Вычисление**
- Supabase Edge Function `compute-weekly-profile`
- Запуск: каждое воскресенье в 03:00 по расписанию
- Вход: сырые данные за последние 7 дней
- Выход: балл 0–100 по каждому измерению + обновление `users.level`

**Применение результата**
- Доступ в комнаты (green/yellow/red из составного скора)
- Персональные материалы в ResourcesScreen
- Мягкая интерпретация на HomeScreen (еженедельная карточка)

## 2. Валидированные тесты

Позиционирование: «психологические тесты для лучшего понимания себя» — не диагноз, не клинический скрининг.

### Профиль — один раз при онбординге

| Тест | Измерение | Вопросов | Источник |
|---|---|---|---|
| ECR-Short | Стиль привязанности (тревожный / избегающий / надёжный) | 6 | Brennan et al. |
| Mini-SPIN | Социальная тревожность | 3 | Connor et al. |

### Еженедельно — ротация, 1–2 теста в неделю

| Тест | Измерение | Вопросов | Источник |
|---|---|---|---|
| GAD-7 | Тревога | 7 | Spitzer et al., 2006 |
| PSS-4 | Стресс | 4 | Cohen et al., 1983 |
| AES-Short | Апатия / потеря смысла | 5 | Marin et al. |
| UCLA-3 | Одиночество | 3 | Russell et al. |

Ротация: каждую неделю система выбирает 1–2 теста с наибольшей давностью прохождения.

### Ежемесячно — 1 тест в месяц

| Тест | Измерение | Вопросов | Источник |
|---|---|---|---|
| OLBI-Short | Выгорание | 8 | Demerouti et al. |
| Rosenberg SES | Самооценка | 10 | Rosenberg, 1965 (публичное достояние) |

## 3. Пассивные поведенческие метрики

Собираются автоматически каждую неделю из существующих таблиц БД.

| Метрика | Источник в БД | Сигнал для измерения |
|---|---|---|
| Количество сообщений в чатах/комнатах | `messages` | Одиночество, соц. тревожность |
| Количество уникальных собеседников в DM | `direct_messages` | Одиночество, стиль привязанности |
| Соотношение «читает» vs «пишет» в комнатах | `messages` + Presence | Социальная тревожность |
| Минуты в рыбалке за неделю | `fishing_sessions` (новая) | Стресс, апатия |
| Частота чекинов настроения | `mood_checkins` | Апатия |
| Тренд чекинов (растёт / падает) | `mood_checkins` | Все измерения |
| Ночная активность 00:00–05:00 | `messages`, `direct_messages` | Тревога, стресс |
| Количество «он мне помог» за неделю | `user_helps` | Самооценка |
| Дней активности в неделю | `messages` + `daily_answers` | Апатия, выгорание |
| Динамика уровня за 4 недели | `test_results` / `user_metrics` | Все измерения |

## 4. Формула подсчёта

### Балл по каждому измерению (0–100, выше = хуже)

```
Балл(измерение) = Тест × 0.6 + Поведение × 0.4
```

Если тест ещё не пройден — поведение даёт 100% до появления тестовых данных.

### Композитный скор

Взвешенное среднее по всем измерениям:

| Измерение | Вес |
|---|---|
| Тревога | 20% |
| Стресс | 20% |
| Апатия | 15% |
| Одиночество | 15% |
| Выгорание | 10% |
| Самооценка | 10% |
| Социальная тревожность | 5% |
| Стиль привязанности | 5% |

### Маппинг в цвет

| Композитный скор | Уровень |
|---|---|
| 0–33 | green |
| 34–66 | yellow |
| 67–100 | red |

## 5. Персональные материалы

### Схема таблицы `resources`

```sql
CREATE TABLE resources (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title TEXT NOT NULL,
  type TEXT CHECK (type IN ('video', 'article')),
  url TEXT NOT NULL,
  topic TEXT NOT NULL,
  dimension_weights JSONB NOT NULL DEFAULT '{}'
);
```

Пример записи:
```json
{
  "title": "Как справиться с тревогой",
  "type": "video",
  "topic": "anxiety",
  "dimension_weights": {
    "anxiety": 0.9,
    "stress": 0.4,
    "loneliness": 0.1
  }
}
```

### Алгоритм подбора при открытии ResourcesScreen

1. Получить текущие баллы пользователя по всем измерениям
2. Для каждого материала: `relevance = Σ(балл_измерения × вес_материала)`
3. Отсортировать по релевантности по убыванию
4. Показать топ-5 в секции «Для тебя сейчас»
5. Остальные — аккордеон «Другие темы» (по категориям)

### Структура экрана

```
┌─────────────────────────────────┐
│  Для тебя сейчас                │
│  [видео]  [статья]  [видео]     │
│                                 │
│  Другие темы                    │
│  > Тревога          (N)         │
│  > Выгорание        (N)         │
│  > Одиночество      (N)         │
│  > Самооценка       (N)         │
│  > Стресс           (N)         │
└─────────────────────────────────┘
```

## 6. Мягкая интерпретация на HomeScreen

Еженедельная карточка — одна фраза, основанная на доминирующем измерении (с наивысшим баллом). Появляется после первой полной недели данных. Под фразой — кнопка «Материалы для тебя».

| Доминирует | Фраза |
|---|---|
| Тревога | «Эта неделя была напряжённой. Ты справляешься.» |
| Стресс | «Много всего навалилось. Дай себе передохнуть.» |
| Одиночество | «Последнее время ты больше наблюдаешь. Это нормально.» |
| Выгорание | «Похоже, ты устал. Не от лени — просто устал.» |
| Апатия | «Сейчас всё кажется серым. Это пройдёт.» |
| Социальная тревожность | «Общение даётся непросто. Ты не один такой.» |
| Самооценка | «Ты справился с кое-чем на этой неделе. Замечаешь?» |
| Улучшение (тренд вниз) | «Эта неделя чуть легче предыдущей.» |
| Норм (composite < 33) | «Ты в порядке. Так и держи.» |

Размещение: отдельная карточка между статус-карточкой уровня и сеткой модулей.

## 7. Новые таблицы БД

```sql
-- Результаты психологических тестов
CREATE TABLE psych_test_results (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(user_id) ON DELETE CASCADE,
  test_id TEXT NOT NULL,        -- 'gad7', 'pss4', 'ecr_short' и т.д.
  scores JSONB NOT NULL,        -- сырые ответы и итоговый балл
  dimension TEXT NOT NULL,      -- 'anxiety', 'stress' и т.д.
  raw_score INT NOT NULL,       -- балл по шкале теста
  normalized_score INT NOT NULL, -- 0–100
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Еженедельные снапшоты метрик
CREATE TABLE user_metrics (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(user_id) ON DELETE CASCADE,
  week_start DATE NOT NULL,
  anxiety_score INT,
  stress_score INT,
  apathy_score INT,
  loneliness_score INT,
  burnout_score INT,
  self_esteem_score INT,
  social_anxiety_score INT,
  attachment_score INT,
  composite_score INT NOT NULL,
  level TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- База материалов
CREATE TABLE resources (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title TEXT NOT NULL,
  type TEXT CHECK (type IN ('video', 'article')),
  url TEXT NOT NULL,
  topic TEXT NOT NULL,
  dimension_weights JSONB NOT NULL DEFAULT '{}'
);
```

## 8. Что НЕ входит в скоуп

- Уведомления о результатах тестов (отдельная фича)
- Экспорт личных метрик пользователем (требует отдельного дизайна)
- AI-интерпретация результатов через Claude API (отдельная фича)
- Сравнение с другими пользователями (запрещено по дизайн-принципам)
- Клинический диагноз или направление к специалисту (вне скоупа продукта)
