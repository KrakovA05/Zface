## Цель

Расширить роль AI в приложении: из генератора постов в ленте — в персонализированный слой, который адаптирует весь опыт под состояние пользователя. Параллельно добавить личный чат с @один как отдельный раздел приложения с заделом под монетизацию.

## Что строим

### 1. Бесплатный AI-слой — везде, незаметно

Четыре компонента, каждый независим:

#### 1.1 Умная лента
Порядок постов в FeedScreen адаптируется под уровень и историю пользователя.
- Red-пользователь видит больше постов с валидацией чувств в начале ленты
- Green-пользователь видит больше вопросов к диалогу
- Ранжирование на стороне клиента: при загрузке постов применяем весовой коэффициент по `target_levels` и `author_level`
- Посты @один с `link_url` (статьи) показываются с учётом `dimension_weights` пользователя из `user_metrics`

#### 1.2 Адаптивный вопрос дня
Вопрос дня в HomeScreen перестаёт быть случайным — он выбирается на основе текущего уровня и динамики за последние 7 дней.
- Уровень ухудшился 3+ дня подряд → вопросы из пула «красной» категории
- Уровень стабильный → нейтральный пул
- Уровень улучшился → вопросы с лёгким вектором на осмысление
- Логика выбора реализуется в клиентском коде при загрузке HomeScreen

#### 1.3 Навигационные подсказки @один
@один изредка появляется в интерфейсе как контекстная карточка — не пуш, не алерт.
- Показывается не чаще 1 раза в день, только при открытии HomeScreen
- Примеры: «Ты сегодня не был на дыхании — может быть сейчас?», «В ленте есть новый пост для твоего состояния»
- Триггеры: 3+ дня без BreathingScreen, новые посты @один по уровню, плохая динамика
- Карточка dismissible, не блокирует контент

#### 1.4 Детекция паттернов
Edge Function `ai-feed-generator` расширяется: перед генерацией проверяет динамику уровня пользователей.
- Если у группы пользователей 3+ дня ухудшение → @один публикует дополнительный пост специально для этой группы
- Реализуется как дополнительный запрос к `test_results` в начале генерации

### 2. Чат с @один — новый раздел

#### 2.1 Навигация
- Таб **Friends** убирается из нижней навигации
- Раздел Друзья остаётся доступным через **ProfileScreen** (кнопка в шапке или секция)
- На 4-ю позицию нижнего таббара добавляется **@один** — иконка ✦ в прямоугольнике цвета `#c9a96e`, поверх иконки в правом верхнем углу стикер **AI** (фон `#7B61FF`, белый текст, 8px)

#### 2.2 Экран чата — AiChatScreen
Новый экран, стилистически близкий к DirectMessageScreen.

**Что видит пользователь:**
- Шапка: аватар @один, имя «@один», подзаголовок «Я здесь каждый день»
- Дисклеймер под шапкой (постоянный, не скрывается): «@один — не психолог и не заменяет специалиста»
- История переписки (сообщения пользователя + ответы @один)
- Поле ввода снизу

**Поведение @один в чате:**
- Знает текущий уровень пользователя и динамику за последние 7 дней
- Знает результаты последнего психологического теста (`psych_test_results`)
- Отвечает в духе системного промпта: без советов, без позитива, как живой человек рядом
- Контекст хранится внутри сессии (последние N сообщений передаются в Gemini)
- Память между сессиями: краткое саммари предыдущей сессии хранится в БД и передаётся как контекст

**Кризисная защита:**
- Список триггерных слов (суицид, не хочу жить, хочу умереть, покончить и т.д.)
- При обнаружении — @один отвечает с теплом, но показывает карточку: «Если тебе сейчас очень тяжело — позвони на линию психологической помощи: 8-800-2000-122 (бесплатно, круглосуточно)»
- @один не продолжает обычный диалог до следующего сообщения пользователя

#### 2.3 База данных — новые таблицы

```sql
-- История сообщений чата
CREATE TABLE ai_chat_messages (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(user_id) ON DELETE CASCADE,
  role TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
  text TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Сессии с саммари для памяти между сессиями
CREATE TABLE ai_chat_sessions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(user_id) ON DELETE CASCADE,
  summary TEXT,
  started_at TIMESTAMPTZ DEFAULT now(),
  ended_at TIMESTAMPTZ
);

-- Флаг для будущей монетизации (сейчас TRUE у всех)
ALTER TABLE users ADD COLUMN IF NOT EXISTS ai_chat_enabled BOOLEAN DEFAULT true;
```

RLS: пользователь видит только свои сообщения и сессии.

#### 2.4 Edge Function — ai-chat

Новая Edge Function `ai-chat`, вызывается из AiChatScreen при отправке сообщения.

**Вход:** `{ user_id, message, session_id? }`  
**Логика:**
1. Загружает профиль пользователя (уровень, психометрика)
2. Загружает последние 20 сообщений текущей сессии
3. Загружает саммари предыдущей сессии (если есть)
4. Проверяет триггерные слова кризиса
5. Формирует промпт для Gemini 2.5 Flash
6. Сохраняет сообщение пользователя и ответ в `ai_chat_messages`
7. Возвращает ответ

**Ответ:** `{ ok, reply, crisis?: true }`
