## 🔴 Блокеры — без этого в стор не попасть

- [ ] **Название приложения** — решить окончательно. Вариант «Ной» обсуждался — метафора: и имя, и «ноет». От названия зависит всё ниже.

- [ ] **Иконка и сплэш** — заменить дефолтные Expo-заглушки на финальный дизайн.

  | Файл | Размер | Примечания |
  |------|--------|-----------|
  | `assets/icon.png` | 1024×1024 PNG | Без прозрачности — iOS не принимает |
  | `assets/adaptive-icon.png` | 1024×1024 PNG | Android, иконка в центральных 66% |
  | `assets/splash-icon.png` | ~512×512 PNG | С прозрачностью, `resizeMode: "contain"` |

- [ ] **Firebase FCM для Android** — без этого push-уведомления на Android не работают в production. Бесплатно, нужно до сборки production-билда.

  1. Создать проект на https://console.firebase.google.com
  2. Добавить Android-приложение (package name из `app.json`)
  3. Скачать `google-services.json`, положить в корень проекта
  4. В `app.json` добавить `"android": { "googleServicesFile": "./google-services.json" }`
  5. `eas credentials` → загрузить FCM credentials

- [ ] **Скрыть личные данные в политике конфиденциальности** — создать GitHub Organization с именем приложения, перенести репо, обновить URL политики. Заменить личный email в `docs/index.html` на отдельный ящик для приложения.

- [ ] **Deep link для подтверждения email** — `EMAIL_CONFIRM_ENABLED` в `config.js` сейчас `false`. Перед релизом: включить в Supabase Dashboard + поставить `true` в коде + настроить deep link, чтобы письмо открывало приложение, а не браузер.
