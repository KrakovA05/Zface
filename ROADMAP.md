- [x] **Ночная комната** — появляется в MessagesScreen и лобби комнат с 23:00 до 06:00. Для тех кому не спится. Таблица `messages` с `level = 'night'`, доступна всем уровням.

- [x] **Контекстные пуши** — ночной пуш (23:00, ночная комната), пятничный пуш (21:00), напоминание о возврате (через 3 дня без открытия — откладывается при каждом запуске).

- [x] **Мягкое отражение присутствия** — карточка в ProfileScreen: «ты здесь уже N дней», «поддержал N человек», «N ответов на вопрос дня». Считается из существующих данных.

- [x] **Анонимное письмо** — экран `LetterScreen`: пишешь письмо в никуда, случайный человек с тем же уровнем получает его завтра. Входящие письма с уведомлением о новом. Таблица `anonymous_letters`. Модуль в HomeScreen.

- [x] **«Похожий на тебя»** — карточка на главном экране (раз в 7 дней): алгоритм находит пользователя с пересечением слов в ответах на вопрос дня. «Кажется, вы похожи» → профиль или «не сейчас». Таблица `similar_user_shown`.

- [x] **Пуш «письмо дошло»** — когда адресат открывает анонимное письмо, отправителю приходит тихий пуш: «твоё письмо дошло». Без имени. Закрывает петлю — человек узнаёт что написал не в пустоту.

- [x] **Пуш «кто-то сказал что ты помог»** — когда кто-то нажимает «Он мне помог» на профиле пользователя, тому приходит пуш: «кто-то написал, что ты им помог». Триггер: INSERT в `user_helps` → push к `helped_id`.

- [x] **Пуш при комментарии к посту** — когда кто-то комментирует твой пост в ленте, автору приходит пуш. INSERT в `post_comments` → push к `author_id` поста.

- [x] **Недельный пуш-отчёт** — каждый понедельник 19:00 один пуш: «эта неделя: X дней подряд · N писем · помог M людям · K ответов». Данные из `login_streak`, `anonymous_letters`, `user_helps`, `daily_answers`.

- [x] **Пуш «сегодня в комнате говорили о...»** — каждое утро в 10:00 пуш с топ-3 словами из комнаты пользователя за последние 24ч. Слова без прямых цитат. Пересчитывается при каждом открытии приложения.

- [x] **Онбординг первых 3 дней** — мягкие подсказки на первый вход: в комнатах «здесь можно просто сидеть молча», на рыбалке «здесь не надо ничего объяснять». AsyncStorage, исчезают через 5 сек или по тапу.
