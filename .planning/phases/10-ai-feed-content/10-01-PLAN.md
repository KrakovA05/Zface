**Функция `callGemini(prompt: string, apiKey: string): Promise<string>`:**
- POST к GEMINI_URL с `?key=${apiKey}`
- Тело: `{ contents: [{ parts: [{ text: prompt }] }] }`
- Извлекает `response.candidates[0].content.parts[0].text`
- При ошибке бросает исключение с текстом статуса

**Функция `generatePostsForLevel(level: string, apiKey: string): Promise<PostItem[]>`:**

Промпты для каждого уровня (в духе приложения — честно, без токсичного позитива):

Для `red` (70% валидация + 30% вопросы):
- Промпт просит 2 поста-валидации и 1 вопрос для обсуждения
- Валидация: "Ты не один. То, что ты чувствуешь — реально.", "Бывает так плохо, что хочется исчезнуть. Это не слабость, это боль."
- Вопрос: "Что сейчас самое тяжёлое — если бы можно было назвать одним словом?"

Для `yellow` (50% валидация + 50% вопросы):
- 1-2 поста-валидации + 1-2 вопроса
- Валидация: "Держаться когда тяжеловато — тоже труд.", "Серые дни — часть жизни, не приговор."
- Вопрос: "Что сейчас требует от тебя больше сил, чем обычно?"

Для `green` (50% вопросы + 30% незаконченные фразы + 20% валидация):
- 1-2 вопроса + 1 незаконченная фраза
- Вопрос: "Что сегодня сделало день чуть лучше?"
- Фраза: "Сегодня мне немного легче, потому что..."

**Системный промпт (общий для всех уровней):**
```

Правила: без советов, без "всё будет хорошо", без эмодзи, без восклицательных знаков, без терапевтического языка.
Максимум 2-3 предложения. Только русский язык. Говори как живой человек, не как психолог.
```
