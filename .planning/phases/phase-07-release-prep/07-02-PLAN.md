<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FCM Service Account Key → EAS | Приватный ключ передаётся через eas credentials, хранится в EAS Secrets |
| google-services.json → git | Содержит только публичные IDs — безопасно коммитить |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Information Disclosure | FCM Service Account Key | mitigate | Добавлен в .gitignore (*service-account*.json, firebase-adminsdk*.json). Загружается только через eas credentials в EAS Secrets. |
| T-07-02-02 | Information Disclosure | google-services.json | accept | Содержит только публичные Firebase идентификаторы (project_id, mobilesdk_app_id, api_key). Google документирует эти поля как безопасные для публичного хранения. |
| T-07-02-03 | Spoofing | FCM push delivery | accept | FCM V1 использует OAuth2 Service Account — авторизация на стороне Google. Expo Push Service выступает посредником только в Expo Go; production-сборка общается с FCM напрямую. |
</threat_model>
