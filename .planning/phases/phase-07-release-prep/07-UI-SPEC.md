## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element padding |
| lg | 24px | Section padding (screen.padding = 24) |
| xl | 32px | Horizontal screen insets (EmailConfirmScreen paddingHorizontal = 32) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch targets minimum 44pt (iOS HIG) — applies to icon-only buttons in any new UI
- Email icon circle: 88pt diameter (existing EmailConfirmScreen pattern — keep)
- Splash safe zone: icon must not exceed 288px of 1242px canvas width (centered)

Source: theme.js shared.screen, shared.button; EmailConfirmScreen styles.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (normal) | 1.5 (24px) |
| Label / hint | 13–14px | 400 (normal) | 1.5 (20px) |
| Heading | 24–28px | 700 (bold) | 1.2 |
| Button text | 16px | 600 (semibold) | 1.0 (single line) |

Notes:
- 28px: shared.title (HomeScreen, main screens)
- 24px: EmailConfirmScreen title — use for any new screen in this phase
- No custom fonts — system defaults only; do NOT introduce new font families in phase 7
- All text in Russian, no emoji in code strings (emoji appear only in constants.js data)

Source: theme.js shared.title (28px bold), shared.subtitle (16px), EmailConfirmScreen styles.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FAF7F2` | Screen backgrounds (colors.background) |
| Secondary (30%) | `#FFFFFF` | Cards, input fields, modals (colors.card) |
| Accent (10%) | `#8B7355` | Primary buttons, active icon circles, email highlight (colors.accent) |
| Destructive | `#E07060` | Destructive actions only — account deletion, report confirm (colors.pink) |
| Border / divider | `#E8DFD0` | Card borders, input outlines (colors.border) |
| Muted text | `#9B8E82` | Secondary text, hints, subtitles (colors.muted) |
| Text primary | `#2C2420` | All body text, headings (colors.white — dark-on-light) |

Accent reserved for:
- Primary CTA buttons (backgroundColor)
- Icon circle in email confirm screen (backgroundColor with 18% opacity overlay)
- Active/selected state of labels
- Interactive link text color

Level semantic colors (existing, do not change):
- Green level: `#4CAF50`
- Yellow level: `#AA7C00` (high-contrast gold)
- Red level: `#F44336`

Source: theme.js colors, constants.js LEVEL_COLORS.

## Asset Specifications

This section is the primary output of Phase 7. All assets must meet App Store and Google Play requirements exactly.

### App Icon

| Property | iOS | Android |
|----------|-----|---------|
| File | `assets/icon.png` | `assets/adaptive-icon.png` (foreground) |
| Canvas size | 1024 × 1024px | 1024 × 1024px foreground layer |
| Background | Solid `#FAF7F2` (app background) | `#FAF7F2` or `#FFFFFF` — in `app.json` |
| Safe zone | Icon art inside center 820 × 820px (80% of canvas) | Art inside center 660 × 660px (66%) |
| Corner radius | None — App Store rounds automatically | None — system applies mask |
| Format | PNG, no transparency | PNG, no transparency (foreground can have alpha) |
| Content | Wordmark or symbol matching final app name | Same symbol, adaptive layer only |

Design intent: warm off-white background (`#FAF7F2`) matching app, simple typographic or abstract mark — no gradients, no shadows on canvas (they bleed at small sizes). Style: quiet, understated, honest — matches app tone.

### Splash Screen

| Property | Value |
|----------|-------|
| File | `assets/splash-icon.png` |
| Canvas | 1242 × 2688px (or Expo default) |
| Background color | `#FAF7F2` (update `app.json` splash.backgroundColor from `#ffffff`) |
| Icon area | Center 288px × 288px max |
| Content | App name or minimal symbol — no taglines |
| resizeMode | `contain` (existing, keep) |
| Fade behavior | System default Expo splash (no custom animation) |

### ASO Screenshots (5 required)

Format and style contract:

| Property | iOS | Android |
|----------|-----|---------|
| Dimensions | 1290 × 2796px (iPhone 15 Pro Max) | 1080 × 1920px |
| Format | PNG |
| Background | `#FAF7F2` — match app background, no artificial device frames unless required |
| Text overlays | Allowed — max 2 lines, 28–36px, weight 700, color `#2C2420` |
| Accent overlays | `#8B7355` — accent chips or badges only |
| Language | Russian only |

Screenshot content plan (5 screens):

| # | Screen | Caption | Key visual |
|---|--------|---------|------------|
| 1 | HomeScreen | «Найди своих — прямо сейчас» | Статус-карточка уровня, чекин настроения |
| 2 | RoomsScreen (red room) | «Комнаты для своих» | Список сообщений, цветные аватары |
| 3 | TestScreen | «Узнай, где ты сейчас» | Вопрос с вариантами ответов |
| 4 | ThoughtsScreen | «Одна мысль — анонимно» | Карточка мысли с реакциями |
| 5 | ProfileScreen | «Ачивки и твой путь» | Сетка достижений, статус |

Screenshot visual rules:
- Use real (or realistic dummy) data — no placeholder text like "Lorem ipsum"
- Show only red/yellow level state — more emotionally resonant for target audience (16–30 лет)
- No marketing language — plain honest Russian copy matching app tone
- No star ratings, no "App of the Year" badges
- Device frame: optional thin rounded rect in `#E8DFD0` border color, or no frame

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (deep link success) | «Войти» |
| Primary CTA (email resend) | «Отправить письмо снова» |
| Empty state heading | N/A — no new list screens in this phase |
| Email confirm success title | «Email подтверждён» |
| Email confirm error title | «Ссылка недействительна» |
| Email confirm error body | «Попробуй войти вручную или запроси новое письмо подтверждения» |
| Email resend success alert | «Готово. Письмо отправлено повторно.» (existing pattern, keep) |
| Email not confirmed alert title | «Письмо ещё не подтверждено» |
| Email not confirmed alert body | «Открой письмо от нас и нажми на ссылку подтверждения.» (existing, keep) |
| Loading state (CTA button) | ActivityIndicator — no text |

Tone rules:
- No formal «Вы» — all copy uses informal «ты»
- No exclamation marks in error/system copy
- No marketing language anywhere in app copy
- Error copy pattern: «[что пошло не так]» + «[что делать]»

Source: Existing EmailConfirmScreen.js copy, app tone from CLAUDE.md.
