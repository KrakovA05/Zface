## Авторизация
- Регистрация, логин, выход
- Подтверждение email (`EmailConfirmScreen`, флаг `EMAIL_CONFIRM_ENABLED` в `config.js`, сейчас `false` — для разработки)
- Согласие с политикой конфиденциальности при регистрации (чекбокс + ссылка)
- Удаление аккаунта через Postgres SECURITY DEFINER функцию `delete_user()`

## Тест и уровни
- Тест из 10 вопросов, 1 раз в 24 часа
- Три уровня: `green` / `yellow` / `red` — цвет аватара и ника везде
- История тестов в `test_results`, динамика (лучше / хуже / стабильно)
- Свитч «Показывать мою динамику» в ProfileScreen (`show_history` в БД)

## Онбординг и рекомендации
- `OnboardingMomentScreen` — после первого теста: сколько человек с тем же уровнем + чужой анонимный ответ дня
- `RecommendationsScreen` — персональные рекомендации + динамика уровня

## Лента
- Посты с фильтром по уровню, фото и видео (Supabase Storage, bucket `post-media`)
- Лайки (таблица `post_likes`), комментарии (`post_comments`, `PostScreen`)
- Удаление своих постов и комментариев
- Актуальный цвет уровня автора (из БД, не из поста)

## Чаты
- Глобальный чат (`ChatScreen`) — realtime, удаление и редактирование своих сообщений, timestamps
- Комнаты по уровню (`RoomsScreen`) — realtime, timestamps, тап аватара → профиль
- Анонимный режим в комнатах — Supabase Presence: счётчик «N человек просто сидят», баннер «войти с именем»
- Реакции на сообщения во всех чатах (таблица `message_reactions`)
- ~~BarScreen~~ — удалён из навигации и HomeScreen

## DM (личные сообщения)
- `DirectMessageScreen` — realtime, timestamps, редактирование и удаление сообщений
- Блокировка проверяется перед отправкой (`blocks`)
- Тап аватара → профиль

## Друзья
- Поиск по никнейму и по ярлыкам (`labels`)
- Заявки в друзья: отправить / принять / отклонить / удалить
- Список друзей с кнопкой перейти в DM

## Профили
- `ProfileScreen` — аватар (base64, редактируемый), статус, достижения (8 ачивок), шер приложения через Share API; счётчик «помог N людям» (таблица `user_helps`)
- `UserProfileScreen` — профиль другого: добавить в друзья / принять / отклонить / удалить, DM, блокировка, жалоба, динамика уровня (если `show_history = true`); кнопка «Он мне помог» с каунтером (таблица `user_helps`)

## Push-уведомления
- Push по новому DM и входящей заявке в друзья
- Проактивные пуши-мини-квесты: 3 в день (9:00 / 13:00 / 19:00), тон зависит от уровня пользователя

## Активности
- `BreathingScreen` — коробочное дыхание 4-4-4-4, Animated-анимация круга
- `FishingScreen` — математически прорисованная удочка (seg-helper / atan2), симпатичный поплавок, 14 рыб с временно́й привязкой, «Записка в бутылке» (вечер/ночь)
- `ThoughtsScreen` — анонимная мысль дня (1 раз в сутки), реакции «я понимаю / я тоже / держись», счётчики

## Главный экран
- Статус-карточка уровня
- Вопрос дня (`daily_answers`) — чужие ответы появляются после своего
- Слово дня (`DAILY_WORDS` в constants.js, таблица `daily_word_taps`) — «ты и ещё N человек чувствуют то же»
- Динамика сообщества — «сегодня X человек с твоим уровнем заходили»
- Напоминание пройти тест, если прошло >3 дней
- Сетка модулей: Лента, Чат, Комнаты, Дыхание, Рыбалка, Мысли, Материалы

## Вовлечение и возврат
- Чекин настроения (1–10) на главном экране, 1 раз в день, показывает сколько людей чувствуют так же (`mood_checkins`)
- Контекстная подсказка после чекина: 1–3 → Дыхание, 4–6 → Комнаты, 7–10 → Лента (пилл под оценкой)
- Пуш поддержки: если 3 дня подряд оценка ≤3 — через 3 часа приходит «Ты держишься» (`scheduleLowMoodPush`)
- Ночная комната — анонимный чат с 23:00 до 06:00, доступен всем уровням (`level='night'`); вход и написание только анонимно, кастомный аватар скрыт
- Контекстные пуши: ночной (23:00), пятничный (21:00), напоминание о возврате через 3 дня
- Мягкое отражение присутствия в ProfileScreen: дней здесь / помог людям / ответов на вопрос дня
- Анонимное письмо (`LetterScreen`): пишешь в никуда, случайный человек с тем же уровнем получает завтра
- «Похожий на тебя» — карточка на главном, раз в 7 дней, алгоритм по пересечению слов в ответах

## Качество и психологическая безопасность
- Тексты уровней (`LEVEL_DATA`) переписаны в безопасном психологическом фрейминге (без «тебе действительно плохо»)
- Дисклеймер «не медицинский диагноз» на экране результата теста
- Кнопка телефона доверия 8-800-2000-122 появляется на результате `red`-уровня
- Кризис-баннер в ChatScreen и DirectMessageScreen — тихо появляется при наборе кризисных фраз
- `DAILY_WORDS_CONTEXT` — рефрейминг для каждого слова дня (25 строк), показывается после тапа «да, это про меня»
- Описания ачивок переписаны — эмоциональные, не механические

## Retention и UX
- Стрик по дням входа: `login_streak` + `last_login_date` в `users`; при первом открытии дня — анимированный модал (`StreakModal.js`, `Animated.spring` + цвет пламени меняется с прогрессом)
- Стрик (последовательные дни с ответом на вопрос дня) — бейдж в шапке HomeScreen
- Счётчик онлайна (активных за последние 10 минут) — бейдж рядом со стриком
- Хаптическая обратная связь: тап слова дня, тап чекина настроения, отправка ответа, отправка/открытие письма
- In-App Review: запрос рейтинга при первом открытии анонимного письма (expo-store-review)
- Кнопка «Узнать где ты сейчас» вместо «Пройти тест»
- История тестов скрыта по умолчанию — раскрывается по кнопке «Список» рядом с графиком
- Empty states переписаны — человечный тон вместо нейтрального
- Слово дня: ответ кешируется в памяти (`wordTapCache`) — не сбрасывается при повторном фокусе экрана
